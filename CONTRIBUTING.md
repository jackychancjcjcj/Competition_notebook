# Contributing

Thank you for helping keep this ML competition knowledge base accurate and useful.

## What belongs here

Each entry should document a public machine-learning or data-science competition and help readers discover trustworthy solution material. Typical categories are:

- Tabular / structured ML
- NLP
- Recommendation systems
- Time series
- Multimodal learning
- Graph learning and knowledge graphs
- Computer vision

## Before opening an issue or pull request

1. Search the README to avoid duplicate competitions.
2. Prefer primary competition pages and public solution repositories or articles.
3. Do not submit private data, credentials, copied paywalled content, or content that violates another site's terms.
4. Check that every link opens and that the claimed placement (for example, winner or top-N) is supported by its source.

## Required fields for a competition entry

Use the existing schema and provide, where available:

```markdown
### Competition name

**Competition link**  
https://...

**Task**  
A concise description of the prediction or modelling task.

**Challenges**  
Key data, metric, validation, or modelling difficulties.

**Solution references**  
[Winning solution](https://...)
[Open-source implementation](https://...)
```

Please include the year, organizer/platform, task type, and result/rank when the source provides them. Keep descriptions factual and concise.

## Pull request checklist

- [ ] This competition is not already listed.
- [ ] Links are public and working.
- [ ] The category and year are correct.
- [ ] The entry uses the repository's `Competition → Task → Challenges → Solution References` structure.
- [ ] Third-party content is summarized in your own words and attributed with a link.

## Maintenance roadmap

Future improvements may include structured metadata, generated indexes, duplicate detection, and link validation. Any automation will remain subject to maintainer review before changes are merged.
